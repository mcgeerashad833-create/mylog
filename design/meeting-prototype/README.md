# MyLog · 会议管理原型

在线画布：https://claude.ai/artifact/8PSUsodGESYrpbwe1By7WL

功能设计：[docs/02-会议管理功能设计.md](../../docs/02-会议管理功能设计.md)

| 文件 | 页面 |
| --- | --- |
| Main.dc.html | ① 会议日程（主界面，可切换今天 / 本周） |
| New.dc.html | ② 新建会议 · 粘贴腾讯会议邀请自动识别 |
| Prep.dc.html | ③ 会议详情 · 会前（议程、上次遗留待办、参会人） |
| Live.dc.html | ④ 会中记录（议程计时、笔记 / 决议 / 待办 / 问题、签到） |
| Minutes.dc.html | ⑤ 会后纪要（自动整理、分享、导入腾讯会议纪要） |
| Actions.dc.html | ⑥ 会议待办（我负责的 / 我跟进的 / 已完成） |

这些是设计画布的源文件（Design Component 格式），需要在上面的画布中查看，不能直接在浏览器中打开。
