# MyLog 部署指南

用一台 Linux 云服务器，通过 Docker 运行 MyLog 和 MySQL，前面用 Nginx 提供 HTTPS。全程大约 20 分钟。

## 需要准备

| 项目 | 说明 |
| --- | --- |
| 云服务器 | Ubuntu 22.04 / 24.04，**1 核 2G** 就够用（MySQL 占大部分内存） |
| 域名 | 例如 `mylog.你的域名.com`，在域名服务商那里加一条 A 记录指向服务器 IP |
| 备案 | 服务器在**中国大陆**的话，域名必须先完成 ICP 备案才能用 80/443 端口访问；香港或海外服务器不需要 |
| 安全组 | 云厂商控制台里放行 **22、80、443** 端口；**不要**放行 3306 和 8787 |

## 1. 安装 Docker 和 Nginx

```bash
ssh root@你的服务器IP

curl -fsSL https://get.docker.com | sh
# 服务器在大陆、上面这条下载很慢时，可以用阿里云镜像：
# curl -fsSL https://get.docker.com | sh -s -- --mirror Aliyun

apt-get update && apt-get install -y nginx certbot python3-certbot-nginx git
```

## 2. 拉代码、设置密码

```bash
git clone https://github.com/mcgeerashad833-create/mylog.git /opt/mylog
cd /opt/mylog

cp .env.example .env
# 生成两个随机密码填进去
sed -i "s|^MYSQL_ROOT_PASSWORD=.*|MYSQL_ROOT_PASSWORD=$(openssl rand -hex 24)|; s|^MYSQL_PASSWORD=.*|MYSQL_PASSWORD=$(openssl rand -hex 24)|" .env
chmod 600 .env
```

> 仓库是私有的，`git clone` 时需要用 GitHub 账号登录，或者在 GitHub 上给这台服务器配一个只读的 Deploy key。

## 3. 启动

```bash
docker compose up -d --build
docker compose ps          # 两个服务都显示 healthy 即可（第一次大约 1–2 分钟）
curl http://127.0.0.1:8787/api/health   # 返回 {"ok":true}
```

数据库表在第一次启动时自动创建，数据保存在 Docker 卷 `mylog_mysql-data` 里，重启、更新都不会丢。

## 4. 配置域名和 HTTPS

```bash
cp deploy/nginx.conf /etc/nginx/sites-available/mylog
sed -i 's/mylog.example.com/你的域名/' /etc/nginx/sites-available/mylog
ln -s /etc/nginx/sites-available/mylog /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

certbot --nginx -d 你的域名     # 按提示填邮箱，选择自动跳转到 HTTPS
```

证书会自动续期。现在打开 `https://你的域名` 就能用了：在「设置」里注册账户，其他设备用同一个账户登录即可同步。

> 一定要用 HTTPS：浏览器只在 HTTPS 页面上允许系统通知（到点提醒），而且密码也需要加密传输。

## 5. 每天自动备份

```bash
crontab -e
# 加入下面这行：每天凌晨 3:30 备份，保留 14 天，备份在 /var/backups/mylog/
30 3 * * * /opt/mylog/deploy/backup.sh >> /var/log/mylog-backup.log 2>&1
```

建议偶尔把备份文件下载到自己电脑上，或者同步到云厂商的对象存储。

恢复某一天的备份：

```bash
gunzip -c /var/backups/mylog/mylog-2026-10-22.sql.gz | \
  docker compose exec -T db sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" mysql -uroot mylog'
```

## 日常维护

| 要做什么 | 命令（在 `/opt/mylog` 下执行） |
| --- | --- |
| 更新到最新版本 | `./deploy/update.sh` |
| 查看运行日志 | `docker compose logs -f app` |
| 重启 | `docker compose restart app` |
| 停止 | `docker compose down`（数据保留） |

## 不用 Docker 的话

也可以直接在服务器上装 Node.js 22.18+ 和 MySQL 8：按 README「开发」一节建库，然后

```bash
npm ci && npm run build && npm prune --omit=dev
DATABASE_URL=mysql://mylog:密码@localhost:3306/mylog TRUST_PROXY=1 node server/index.ts
```

再用 systemd 或 pm2 让它常驻，Nginx 配置相同。
