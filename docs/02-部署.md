# MyLog 部署指南

一台 Linux 云服务器用 Docker 运行 MyLog，数据存在**云数据库**（阿里云 RDS MySQL、腾讯云 MySQL 等），前面用 Nginx 提供 HTTPS。全程大约 30 分钟。

```
手机 / 电脑浏览器 ──HTTPS──▶ Nginx ──▶ MyLog 容器 ──内网──▶ 云数据库 MySQL
                           （同一台云服务器）
```

部署时配合 [03-上线检查清单.md](03-上线检查清单.md) 逐项确认。

## 需要准备

| 项目 | 说明 |
| --- | --- |
| 云服务器 | Ubuntu 22.04 / 24.04，**1 核 1G** 就够用（数据库不在这台机器上） |
| 云数据库 | **MySQL 8.0**，最低配置即可；和云服务器**同一个地域、同一个 VPC**，这样能走内网 |
| 域名 | 例如 `mylog.你的域名.com`，在域名服务商那里加一条 A 记录指向服务器公网 IP |
| 备案 | 服务器在**中国大陆**的话，域名必须先完成 ICP 备案才能用 80/443 端口访问；香港或海外服务器不需要 |
| 安全组 | 云服务器只放行 **22、80、443** 端口；**不要**放行 8787 |

## 1. 准备云数据库

在云厂商控制台里操作（阿里云叫「云数据库 RDS」，腾讯云叫「云数据库 MySQL」，步骤大同小异）：

1. **创建实例**：MySQL 8.0，地域和 VPC 选得和云服务器一样。
2. **建数据库**：库名 `mylog`，字符集 **utf8mb4**。
3. **建账号**：账号 `mylog`，设一个强密码，只给 `mylog` 这个库「读写」权限。
4. **白名单 / 安全组**：只加云服务器的**内网 IP**（例如 `172.16.0.12`）。不要填 `0.0.0.0/0`。
5. **记下内网地址**：实例详情里的「内网地址」，例如 `rm-xxxx.mysql.rds.aliyuncs.com` 或 `10.0.0.8`，端口一般是 3306。
6. **打开自动备份**：控制台里的「备份恢复」设为每天备份，保留 7 天以上。这是最主要的备份。

> 不需要手动建表：MyLog 第一次启动时会自动创建。

## 2. 安装 Docker 和 Nginx

```bash
ssh root@你的服务器IP

curl -fsSL https://get.docker.com | sh
# 服务器在大陆、上面这条下载很慢时，可以用阿里云镜像：
# curl -fsSL https://get.docker.com | sh -s -- --mirror Aliyun

apt-get update && apt-get install -y nginx certbot python3-certbot-nginx git
```

## 3. 拉代码、填数据库连接串

```bash
git clone https://github.com/mcgeerashad833-create/mylog.git /opt/mylog
cd /opt/mylog

cp .env.example .env
nano .env        # 把 DATABASE_URL 改成你的云数据库
chmod 600 .env
```

`.env` 里这一行，换成第 1 步记下的信息：

```
DATABASE_URL=mysql://mylog:你的密码@数据库内网地址:3306/mylog
```

- **密码里有特殊符号**（`@ : / ? # %` 等）时要做 URL 编码，例如密码 `a@b#1` 写成 `a%40b%231`。可以用 `node -e "console.log(encodeURIComponent('你的密码'))"` 或在线工具转换。
- **只能走公网连接**（云服务器和数据库不在同一个 VPC）时，必须开启 SSL，见下面「走公网连接」。

> 仓库是私有的，`git clone` 时需要用 GitHub 账号登录，或者在 GitHub 上给这台服务器配一个只读的 Deploy key。

## 4. 启动

```bash
docker compose up -d --build
docker compose ps                         # 显示 healthy 即可（第一次构建大约 1–2 分钟）
curl http://127.0.0.1:8787/api/health     # 返回 {"ok":true}
```

连不上数据库时，`docker compose logs app` 里会看到原因，常见的有：

| 日志里的报错 | 原因 |
| --- | --- |
| `ETIMEDOUT` / `connect ECONNREFUSED` | 地址或端口不对；或者数据库白名单没加云服务器的内网 IP；或者两者不在同一个 VPC |
| `Access denied for user 'mylog'@'…' (using password: YES)` | 账号或密码不对 |
| `TypeError: Invalid URL` | 密码里的特殊符号没做 URL 编码 |
| `Access denied for user 'mylog'@'%' to database '…'` | 库名写错，或者账号没有这个库的权限 |
| `self-signed certificate in certificate chain` | 走公网时 `deploy/db-ca.pem` 不是这个数据库的 CA 证书，或者数据库还没开启 SSL |

配错时容器会不停重启（`docker compose ps` 显示 `Restarting`），改好 `.env` 后执行 `docker compose up -d` 即可。

### 走公网连接（云服务器和数据库不在同一个 VPC 时）

数据会经过公网，必须加密并校验数据库的证书：

1. 云数据库控制台里**开启 SSL**（阿里云：数据安全性 → SSL；腾讯云：数据安全 → SSL），然后**下载 CA 证书**。
2. 把 CA 证书（`.pem` 文件）上传到服务器的 `/opt/mylog/deploy/db-ca.pem`。
3. `.env` 里的 `DATABASE_URL` 用数据库的**外网地址**。
4. 打开 `docker-compose.yml`，把 `DATABASE_CA_FILE` 和 `volumes` 那三行前面的 `#` 去掉，然后 `docker compose up -d`。
5. 数据库白名单里加云服务器的**公网 IP**。

## 5. 配置域名和 HTTPS

```bash
cp deploy/nginx.conf /etc/nginx/sites-available/mylog
sed -i 's/mylog.example.com/你的域名/' /etc/nginx/sites-available/mylog
ln -s /etc/nginx/sites-available/mylog /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

certbot --nginx -d 你的域名     # 按提示填邮箱，选择自动跳转到 HTTPS
```

证书会自动续期。现在打开 `https://你的域名` 就能用了：在「设置」里注册账户，其他设备用同一个账户登录即可同步。手机上可以在浏览器里「添加到主屏幕」，用起来像一个 App。

> 一定要用 HTTPS：浏览器只在 HTTPS 页面上允许系统通知（会前提醒、到点提醒），而且密码也需要加密传输。

## 6. 备份

**主力是云数据库自带的自动备份**（第 1 步第 6 条），恢复时在控制台里按时间点恢复即可。

想在云服务器上再多留一份导出文件的话（配了 CA 证书时会自动用加密连接导出）：

```bash
crontab -e
# 加入下面这行：每天凌晨 3:30 导出一份，保留 14 天，放在 /var/backups/mylog/
30 3 * * * /opt/mylog/deploy/backup.sh >> /var/log/mylog-backup.log 2>&1
```

用导出文件恢复某一天的数据（会覆盖数据库里的现有数据，操作前先确认）：

```bash
cd /opt/mylog
docker compose exec -T app node -e 'const u=new URL(process.env.DATABASE_URL);console.log(u.hostname,u.port||3306,decodeURIComponent(u.username),decodeURIComponent(u.pathname.slice(1)))'
# 用上面打印出的 地址 端口 账号 库名，执行：
gunzip -c /var/backups/mylog/mylog-2026-10-22.sql.gz | \
  docker run --rm -i --network host -e MYSQL_PWD='你的密码' mysql:8.0 mysql -h 地址 -P 端口 -u 账号 库名
```

## 日常维护

| 要做什么 | 命令（在 `/opt/mylog` 下执行） |
| --- | --- |
| 更新到最新版本 | `./deploy/update.sh` |
| 查看运行日志 | `docker compose logs -f app` |
| 重启 | `docker compose restart app` |
| 停止 | `docker compose down`（数据在云数据库里，不受影响） |
| 改了 `.env` 之后生效 | `docker compose up -d` |

## 不用 Docker 的话

也可以直接在服务器上装 Node.js 22.18+：

```bash
npm ci && npm run build && npm prune --omit=dev
DATABASE_URL='mysql://mylog:密码@数据库内网地址:3306/mylog' TRUST_PROXY=1 node server/index.ts
```

再用 systemd 或 pm2 让它常驻，Nginx 配置相同。
