# MyLog · 会议管理 — 功能设计（v0.1，待审核）

> 一句话定位：**会前有准备，会中有记录，会后有人跟。每个会都留下结论和待办，而且待办会落到你的「今天」里。**

适用场景：**腾讯会议（线上）**、**线下会议室**、**混合会议**（会议室里一部分人，其他人用腾讯会议接入）。

---

## 1. 问题与目标用户

**用户画像**：每周要开不少会的人——既有腾讯会议，也有线下碰头；有时是组织者（要发通知、定议程、写纪要），更多时候是参会者（要记住结论和自己领的活）。

**核心痛点**

| 痛点 | 表现 |
| --- | --- |
| 信息散 | 腾讯会议邀请在微信群里刷走了，开会前到处翻会议号和密码；线下会议记不清是哪间会议室 |
| 会开偏 | 没有议程，说着说着跑题，时间到了正事没谈完 |
| 没记录 | 结论靠记忆，过两天各说各的；线下会议没有录制 |
| 没人跟 | 会上分了活，会后没人追；下次开会又把上次的事重新讨论一遍 |

**产品目标**：
1. 开会前 1 分钟内能**找到并进入**会议（腾讯会议一键入会 / 线下看到地点）。
2. 会中**边开边记**，结论和待办随手标出来，不用会后再整理。
3. 会后 **5 分钟内**发出一份像样的纪要。
4. 会上领的活**自动进入 MyLog 的「今天 / 以后」**，别人领的活能看到进度。

**定位边界**：我们**不替代腾讯会议**的音视频能力，而是做它旁边的「会议笔记本 + 待办跟踪器」。

## 2. 竞品参考

| 产品 | 值得学的点 | 我们的取舍 |
| --- | --- | --- |
| **腾讯会议** | 日程、会议号/链接入会、云录制、AI 小助手与智能纪要 | ✅ 作为入会和录制的工具，我们负责会前会后；支持导入它导出的纪要/转写文本 |
| **飞书会议 + 妙记** | 会议与文档、纪要打通；转写后可点句子回放 | ✅ 学“会议 ↔ 纪要”绑定；转写回放暂不做 |
| **Fellow / Hugo** | 会前协作议程；**上次未完成的待办自动带进下次议程**；会议模板 | ✅ **核心借鉴**：例会的待办延续 |
| **Notion / 飞书文档会议模板** | 固定结构：议程 / 讨论 / 决议 / 待办 | ✅ 纪要结构照这个来，但由系统自动整理 |
| **通义听悟 / Otter** | 线下录音实时转写、自动摘要 | ⏸ 放 P1/P2，先看你是否真的需要录音 |
| **Google Calendar / Outlook** | 日程视图、会前提醒、地点 | ✅ 日程列表 + 提醒；不做完整日历 |

**我们刻意不做的**：会议室预订审批、视频通话、多人实时协同编辑纪要、复杂的权限体系。

## 3. 核心概念

```
 会议邀请（粘贴 / 手动）
        │
        ▼
   ┌─ 会前 ──────────┐   ┌─ 会中 ──────────┐   ┌─ 会后 ──────────┐   ┌─ 跟进 ──────────┐
   │ 时间 · 入会方式 │──▶│ 议程计时        │──▶│ 自动生成纪要    │──▶│ 我的待办 → 今天 │
   │ 议程 · 参会人   │   │ 笔记 / 决议 /   │   │ 确认待办负责人  │   │ 别人的待办 → 跟进│
   │ 上次遗留待办    │   │ 待办 / 问题     │   │ 复制发群 / 导出 │   │ 下次例会自动带入 │
   └─────────────────┘   └─────────────────┘   └─────────────────┘   └─────────────────┘
```

- **会议**：一次具体的会。入会方式三选一：腾讯会议 / 线下 / 混合。
- **系列（例会）**：周会、双周会等重复的会，共享模板，待办会延续。
- **议程**：会议要谈的几件事，每件有预计时长、负责人。
- **记录**：会中写下的内容，每条可以标成 **笔记 / 决议 / 待办 / 问题**。
- **待办**：有负责人、截止日期；负责人是“我”时，自动成为 MyLog 的任务。
- **纪要**：会后由记录自动整理出来的文档，可修改后发出。

## 4. 功能清单与优先级

### P0 · 第一版必须有

| # | 功能 | 说明 |
| --- | --- | --- |
| M1 | **会议日程** | 今天 / 本周的会议列表；每个会显示类型（腾讯会议 / 线下 / 混合）、时间、状态（即将开始 / 进行中 / 待整理纪要 / 已完成）；最近一场显示倒计时 |
| M2 | **粘贴腾讯会议邀请自动识别** | 把腾讯会议的邀请文字整段粘贴进来，自动识别主题、时间、会议号、密码、入会链接，确认后保存。也可以手动新建 |
| M3 | **一键入会** | 腾讯会议：打开入会链接（唤起腾讯会议客户端），或一键复制「会议号 + 密码」；线下：显示地点 / 会议室 |
| M4 | **议程** | 会前列出要谈的几件事，每件填预计时长和负责人；总时长超过会议时长时提示 |
| M5 | **会中记录** | 按议程分段记录；输入时可选标记：笔记 / 决议 / 待办 / 问题（也支持快捷前缀 `决：` `待：` `问：`）；待办里写 `@某人` `周五前` 自动识别负责人和截止日期 |
| M6 | **议程计时** | 显示当前议程项已用时间 / 预计时间，超时变色提醒；一键进入下一项 |
| M7 | **自动生成纪要** | 会后自动整理成：基本信息 / 参会人 / 各议程要点 / 决议 / 待办（负责人 + 截止）/ 遗留问题；可修改 |
| M8 | **一键分享纪要** | 复制为适合微信 / 企业微信群的纯文本；复制为 Markdown；导出 PDF |
| M9 | **会议待办跟踪** | 「我负责的」自动进入 MyLog「今天 / 以后」，完成状态双向同步；「我跟进的」（别人负责）单独列出，逾期标红，可一键复制催办消息 |
| M10 | **提醒** | 会前 N 分钟提醒（线下会议可设更早，留出走过去的时间）；会后 30 分钟还没整理纪要时提醒一次 |

### P1 · 让人愿意一直用

| # | 功能 | 说明 |
| --- | --- | --- |
| M11 | **例会 / 系列会议** | 周会等重复会议一次设置；议程模板复用；**上次没完成的待办自动带进本次议程第一项** |
| M12 | **线下签到** | 线下 / 混合会议在参会人名单上点选到场、缺席，纪要里自动写入 |
| M13 | **导入腾讯会议智能纪要 / 转写** | 粘贴或上传腾讯会议导出的纪要、转写文本，自动拆出决议和待办候选，由你确认 |
| M14 | **会议资料** | 给会议挂链接或文件（方案、PPT、表格） |
| M15 | **搜索** | 搜索所有纪要、决议、待办（例如“上次关于预算是怎么定的”） |
| M16 | **常用参会人** | 记住常一起开会的人，输入 `@` 即可选 |

### P2 · 以后再说

- M17 **腾讯会议开放平台对接**：自动同步我的腾讯会议日程、参会记录、云录制与转写（需企业版 / 商业版账号，具体能力以开放平台文档为准）
- M18 **线下录音转写**：浏览器录音，会后转成文字（涉及隐私，需要明确提示与同意）
- M19 **AI 纪要草稿**：从记录或转写文本生成纪要初稿与待办建议
- M20 **会议统计**：每周开会时长、会议占比、待办按时完成率
- M21 **日历导出**：生成 .ics，订阅到系统日历

## 5. 关键用户流程

**① 收到腾讯会议邀请（目标 < 10 秒）**
在微信里复制邀请 → MyLog 里 `Ctrl/⌘+K` 粘贴 → 自动识别出「产品周会 · 10月23日 10:00–11:00 · 会议号 123 456 789」→ 回车保存。

**② 开会前**
提前 10 分钟收到提醒 → 打开会议看到议程和上次遗留的 2 条待办 → 点「入会」打开腾讯会议；线下会议则看到「3 楼 小会议室」。

**③ 会中**
进入「会中记录」→ 计时器开始 → 按议程逐项记录，遇到结论选「决议」，分了活选「待办」并写 `@李娜 周五前` → 一项谈完点「下一项」。

**④ 会后**
点「结束会议」→ 自动生成纪要 → 检查待办负责人和截止日期 → 「复制为微信文本」发到群里 → 我负责的 2 条待办已出现在「今天 / 以后」。

**⑤ 下次例会**
打开下周的产品周会 → 议程第一项自动是「上次待办回顾（2 条未完成）」。

## 6. 界面规划

| 页面 | 内容 |
| --- | --- |
| ① 会议日程（主界面） | 左侧 MyLog 边栏新增「会议」分组；中间是今天 / 本周会议列表；最近一场以大卡片显示倒计时和入会按钮；右侧显示待整理纪要和我的会议待办 |
| ② 新建会议 | 粘贴腾讯会议邀请自动识别；切换 腾讯会议 / 线下 / 混合；议程与提醒 |
| ③ 会议详情 · 会前 | 入会方式、议程、参会人、上次遗留待办、资料 |
| ④ 会中记录 | 议程计时 + 按议程分段的记录 + 标记类型 + 签到 |
| ⑤ 会后纪要 | 自动整理的纪要预览、待办确认、分享 |
| ⑥ 会议待办 | 我负责的 / 我跟进的 / 已完成，按会议分组 |

视觉风格沿用 MyLog：白底、浅灰边栏、一种主色（蓝），会议类型用三种浅色标签区分。

界面原型：见「会议管理原型」画布（6 屏），源文件在 [design/meeting-prototype](../design/meeting-prototype)。

## 7. 待你确认的问题

1. **独立工具还是 MyLog 的一个模块？** 本稿按“MyLog 里新增「会议」分组”设计，这样会议待办可以直接进「今天」。如果你想要独立工具，界面结构基本不变。
2. **腾讯会议账号是个人版还是企业版 / 商业版？** 这决定能不能做 M17 自动同步；个人版就靠“粘贴邀请 + 导入纪要”。
3. **纪要只是自己记，还是要给别人看 / 一起编辑？** 本稿是“自己记 + 复制发群”，不做多人协同编辑。
4. **线下会议需要录音转写吗？** 需要的话 M18 可以提前到 P1。
5. **你更多是组织者还是参会者？** 组织者更需要议程和发通知，参会者更需要记录和待办。
