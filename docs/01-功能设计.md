# MyLog · 每日琐事管理工具 — 功能设计（v0.1 待审核）

> 一句话定位：**把脑子里乱糟糟的琐事倒出来，排成今天的一条清单，一条一条划掉。**

---

## 1. 问题与目标用户

**用户画像**：每天被大量小事包围的人——回个消息、交个表、买个东西、打个电话、催一下进度。单件事都不难，难在“多、碎、容易忘”。

**核心痛点**

| 痛点 | 表现 |
| --- | --- |
| 记不住 | 事情冒出来的瞬间没记下，过后就忘 |
| 理不清 | 一堆事堆在一起，不知道先做哪件 |
| 做不完 | 清单越拉越长，看着焦虑，干脆不看 |
| 没反馈 | 一天忙完说不出做了什么，没有成就感 |

**产品目标**：记录要快（< 3 秒）、今天要清楚（只看今天该做的）、完成要爽（划掉有反馈）、回顾有数（每天留下“工作日志”——这也呼应项目名 *MyLog*）。

## 2. 竞品参考：向优秀产品学习

| 产品 | 最值得学的点 | 我们的取舍 |
| --- | --- | --- |
| **Things 3** | 「收件箱 → 今天 → 计划中 → 随时 → 某天」的分层；界面极简、留白克制；完成时的小动画 | ✅ 学习分层思路与视觉克制，简化为三层 |
| **Todoist** | 自然语言快速添加（“明天下午3点 给王总打电话 #工作 p1”自动解析）；Karma 连续完成激励 | ✅ 快速添加 + 自然语言解析是 P0；激励做轻量版 |
| **滴答清单 TickTick** | 中文语境友好；番茄钟、习惯打卡、日历视图一体化 | ✅ 中文日期解析；番茄钟放 P2；不做习惯打卡（避免功能膨胀） |
| **Microsoft To Do** | 「我的一天」：每天清空、从建议中手动挑选今日任务 | ✅ **核心借鉴**：每天早上“挑选今天要做的事” |
| **Sunsama** | 每日计划仪式（早上规划、晚上复盘）；未完成任务一键顺延 | ✅ 学习“晚间复盘 + 顺延”，做成 1 分钟轻量版 |
| **Any.do** | 「Plan my day」逐条过一遍待办，决定今天做/改期/删除 | ✅ 并入每日规划流程 |
| **Apple 提醒事项** | 系统级快速录入、地点/时间提醒 | ⏸ 地点提醒暂不做 |

**我们刻意不做的**：项目管理（甘特图、多人协作、看板）、复杂的标签/过滤器体系。我们的对手不是 Jira，而是**便利贴和脑子**。

## 3. 核心概念（信息架构）

```
 收集箱 Inbox ──(规划)──▶ 今天 Today ──(完成)──▶ 日志 Log
     ▲                     │
     │                     └─(没做完)──▶ 顺延到明天 / 放回收集箱 / 删除
 随手记录                  
                         以后 Later（有日期的未来任务，到期自动进入“今天”）
```

- **收集箱**：所有随手记下、还没决定什么时候做的事。
- **今天**：今天承诺要做的事，**主界面**。
- **以后**：有明确日期的事，到日子自动出现在“今天”。
- **日志**：已完成事项按天归档，形成每日工作记录。

只有一个维度——**时间**。不强制分类，降低认知负担。

## 4. 功能清单与优先级

### P0 · MVP 必须有（不做就不成立）

| # | 功能 | 说明 | 参考 |
| --- | --- | --- | --- |
| F1 | **快速添加** | 顶部常驻输入框，回车即存；全局快捷键 `Ctrl/⌘+K` 随时唤起；默认进“今天” | Todoist、Things |
| F2 | **中文智能解析** | 识别“明天 / 周五 / 下午3点 / 每周一”等时间词、`!` 标重要、`#标签`，解析结果以高亮小标签预览，可点掉 | Todoist、滴答 |
| F3 | **今天清单** | 一条条列出今天的事；顶部显示进度「已完成 5 / 12」与进度条 | MS To Do |
| F4 | **一键完成** | 点圆圈即完成：划线 + 打勾动画 + 轻微音效（可关），1 秒后沉到“已完成”折叠区；支持撤销 | Things |
| F5 | **拖拽排序** | 手动调整先后顺序，顺序即优先级 | Things |
| F6 | **编辑与删除** | 点击展开：改标题、加备注、改日期；左滑/快捷键删除 | 通用 |
| F7 | **收集箱** | 不确定时间的事放这里，不干扰今天 | Things |
| F8 | **未完成自动处理** | 过了零点，昨天没做完的事在“今天”顶部单独显示为「昨天遗留 3 件」，可一键全部顺延或逐条处理 | Sunsama |
| F9 | **本地数据存储** | 离线可用，打开即用，无需注册 | — |

### P1 · 让人愿意天天用

| # | 功能 | 说明 | 参考 |
| --- | --- | --- | --- |
| F10 | **早间规划（1 分钟）** | 每天首次打开时弹出：从收集箱 / 遗留 / 今日到期中逐条选「今天做 / 改天 / 删除」 | Any.do、MS To Do |
| F11 | **晚间复盘 / 每日日志** | 自动生成当天日志：完成了哪些、用时分布；可补一句今日总结 | Sunsama |
| F12 | **重要标记** | 只有一档“重要”（星标），重要事项置顶。不做 P1–P4 四档，避免纠结 | 克制版 Todoist |
| F13 | **子步骤** | 一件事可拆 2–5 个小步骤（如“交报销：贴票 → 签字 → 交财务”） | Things 清单项 |
| F14 | **重复任务** | 每天 / 每周 X / 每月 X 号，例如“每周一交周报” | 滴答 |
| F15 | **提醒** | 到点浏览器/系统通知 | 通用 |
| F16 | **完成激励** | 连续“清空今天”的天数（🔥 连续 7 天）；清空当天清单时出现庆祝页 | Todoist Karma（轻量） |
| F17 | **搜索** | 全局搜索任务与历史日志 | 通用 |

### P2 · 以后再说

- F18 番茄专注：对单条任务开 25 分钟计时（滴答）
- F19 日历视图：按月查看安排与完成情况
- F20 数据统计：每周完成数趋势、最常拖延的事
- F21 多端同步（需账号体系）

## 5. 关键用户流程

**① 随手记一件事（目标 < 3 秒）**
`Ctrl+K` → 输入“明天上午 给物业打电话 !” → 回车 → 提示“已加入 明天 · 重要”

**② 早上开始一天**
打开 → 早间规划卡片（遗留 2 件 + 收集箱 4 件 + 今日到期 3 件）→ 逐条选择 → 生成今日清单「共 7 件」

**③ 一条条完成**
今天列表 → 从上往下做 → 点圆圈 ✓ → 进度条前进 → 全部完成 → 🎉 庆祝页 +「连续 3 天清空」

**④ 晚上收尾**
点击「结束今天」→ 看到今日日志（完成 6 件，未完成 1 件）→ 未完成项选择顺延 → 写一句总结（可跳过）

## 6. 界面规划（下一步绘制）

| 页面 | 内容 |
| --- | --- |
| 主界面 · 今天 | 左侧边栏（今天 / 收集箱 / 以后 / 日志）+ 中间清单 + 顶部快速添加 |
| 任务详情 | 右侧抽屉：标题、备注、日期、子步骤、重复 |
| 早间规划 | 卡片式逐条决策 |
| 每日日志 / 复盘 | 当天完成时间线 + 总结 |
| 清空庆祝 | 全部完成后的反馈页 |

形态建议：**先做 Web 版（桌面浏览器优先，同时适配手机宽度）**，数据存本地，后续再考虑同步。

视觉风格：参考 Things 的克制留白，大量白色 + 一种主色，强调“清单感”而非“系统感”。

## 7. 需要你确认的问题

1. **使用场景**：主要在电脑上用，还是手机上用？（决定界面先做哪个）
2. **范围**：P0 + P1 作为第一版是否合适？有没有你觉得多余或缺失的？
3. **激励元素**（音效、连续天数、庆祝页）：喜欢，还是希望更安静克制？
4. **“日志/周报”**：项目叫 MyLog，是否希望“工作日志 + 自动生成周报”成为核心卖点，从 P2 提到 P1？
5. **数据**：仅本地存储可以接受吗？还是一开始就需要多设备同步？

确认后我开始绘制界面原型。
