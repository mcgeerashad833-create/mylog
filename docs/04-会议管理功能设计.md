# MyLog · 会议管理 — 功能设计（v0.2）

> 一句话定位：**作为参会者，开会前找得到会，开会时随手记，开完会知道自己要做什么。会上领的活直接进你的「今天」。**

形态：**MyLog 的一个模块**（边栏新增「会议」分组），不是独立工具。

适用场景：**腾讯会议（个人版）**、**线下会议**、**混合会议**（会议室里一部分人，其他人用腾讯会议接入）。

---

## 1. 问题与目标用户

**用户画像**：经常**参加**会议的人（不是组织者）。会议由别人发起，你收到腾讯会议邀请或线下通知，到点参加，会上听、提问、领活。

**核心痛点**

| 痛点 | 表现 |
| --- | --- |
| 找不到会 | 腾讯会议邀请在微信群里刷走了，开会前到处翻会议号和密码；线下会议记不清是哪间会议室 |
| 记不住 | 会上说了什么、定了什么，过两天就模糊了 |
| 漏了活 | 会上自己答应的事，会后忘了做；别人答应你的事，也没人提醒你去问 |

**产品目标**：
1. 开会前 1 分钟内能**找到并进入**会议（腾讯会议一键入会 / 线下看到地点）。
2. 会中**随手记**，结论和待办当场标出来。
3. 会后 **5 分钟内**整理好自己的纪要。
4. 会上领的活**自动进入 MyLog 的「今天 / 以后」**。

**定位边界**：不替代腾讯会议的音视频；不做组织者功能（议程、发通知、签到）；纪要只给自己看，不做多人协同。

## 2. 竞品参考

| 产品 | 值得学的点 | 我们的取舍 |
| --- | --- | --- |
| **腾讯会议** | 日程、会议号 / 链接入会、AI 小助手与智能纪要 | ✅ 用它入会；支持粘贴它导出的智能纪要文字来补充记录 |
| **Fellow / Hugo** | 例会的待办延续到下一次 | ✅ 借鉴：上次留给我的待办，下次开会前自动显示 |
| **Notion / 飞书文档会议模板** | 纪要结构：决议 / 待办 / 遗留问题 | ✅ 纪要按这个结构自动整理 |
| **Google Calendar** | 日程列表、会前提醒、地点 | ✅ 只做会议列表 + 提醒，不做完整日历 |

**刻意不做的**：议程管理与议程计时、线下签到、录音转写、腾讯会议开放平台对接（个人版用不了）、多人协同编辑纪要、会议室预订。

## 3. 核心概念

```
 腾讯会议邀请（粘贴）/ 线下会议（手动）
        │
        ▼
   ┌─ 会前 ──────────────┐   ┌─ 会中 ─────────────┐   ┌─ 会后 ─────────────┐   ┌─ 跟进 ─────────────────┐
   │ 时间 · 入会方式      │──▶│ 随手记，每条可标成 │──▶│ 自动整理成纪要      │──▶│ 我的待办 → 今天 / 以后  │
   │ 会前备注（想问的事）│   │ 笔记/决议/待办/问题 │   │ 核对待办负责人和日期│   │ 别人答应我的 → 我跟进的 │
   │ 上次留给我的待办     │   │                    │   │                    │   │ 例会下次自动带出        │
   └─────────────────────┘   └────────────────────┘   └────────────────────┘   └────────────────────────┘
```

- **会议**：一次具体的会。类型三选一：腾讯会议 / 线下 / 混合。
- **例会**：周会等重复的会，上次留下的待办会在下一次自动显示。
- **记录**：会中写下的内容，每条可以标成 **笔记 / 决议 / 待办 / 问题**，带会议进行到的时间点。
- **待办**：有负责人、截止日期。负责人是“我”时，自动成为 MyLog 的任务；负责人是别人时，进入「我跟进的」。
- **纪要**：会后由记录自动整理出来，只给自己看；需要时可以复制出去。

## 4. 功能清单与优先级

### P0 · 第一版必须有

| # | 功能 | 说明 |
| --- | --- | --- |
| M1 | **会议日程** | 今天 / 本周的会议列表；每个会显示类型（腾讯会议 / 线下 / 混合）、时间、地点或会议号、状态（即将开始 / 进行中 / 待整理 / 已整理）；最近一场显示倒计时 |
| M2 | **粘贴腾讯会议邀请自动识别** | 整段粘贴腾讯会议邀请，自动识别主题、时间、会议号、密码、入会链接，确认后保存；线下会议手动填时间和地点 |
| M3 | **一键入会** | 腾讯会议：打开入会链接（唤起腾讯会议客户端），或一键复制「会议号 + 密码」；线下：显示地点 |
| M4 | **会中记录** | 一条条随手记，自动带上时间点；可标记为 笔记 / 决议 / 待办 / 问题（也支持前缀 `决：` `待：` `问：`）；待办里写 `@某人` `周五前` 自动识别负责人和截止日期 |
| M5 | **自动整理纪要** | 会后整理成：基本信息 / 决议 / 待办（负责人 + 截止）/ 要点 / 遗留问题；可修改；没指定负责人的待办会提示补全 |
| M6 | **会议待办** | 「我负责的」自动进入 MyLog「今天 / 以后」，两边完成状态同步；「我跟进的」（别人答应我的）单独列出，逾期标红，可一键复制催问消息 |
| M7 | **提醒** | 会前 N 分钟提醒（线下会议多留几分钟走过去）；会后 30 分钟还没整理纪要时提醒一次 |

### P1 · 让人愿意一直用

| # | 功能 | 说明 |
| --- | --- | --- |
| M8 | **例会** | 周会等重复会议一次设置；上次留给我的待办在下一次会议详情和会中记录里自动显示 |
| M9 | **会前备注** | 开会前记下想问的问题、要带的资料；会中显示在旁边，说到了就勾掉 |
| M10 | **导入腾讯会议智能纪要** | 粘贴腾讯会议导出的智能纪要文字，自动找出自己漏记的决议和待办，确认后合并 |
| M11 | **复制 / 导出纪要** | 需要转给别人时，复制为微信文本 / Markdown，或导出 PDF |
| M12 | **搜索** | 搜索所有纪要、决议、待办（例如“上次关于预算是怎么定的”） |

### P2 · 以后再说

- M13 **AI 纪要初稿**：从会中记录生成更通顺的纪要和待办建议
- M14 **会议统计**：每周开会时长、我的会议待办按时完成率
- M15 **日历导出**：生成 .ics，订阅到系统日历

## 5. 关键用户流程

**① 收到腾讯会议邀请（目标 < 10 秒）**
在微信里复制邀请 → MyLog 里 `Ctrl/⌘+K` 粘贴 → 自动识别出「产品周会 · 10月22日 10:00–11:00 · 会议号 123 456 789」→ 回车保存。

**② 开会前**
提前 10 分钟收到提醒 → 打开会议，看到上次留给我的 1 条待办和自己的会前备注 → 点「入会」打开腾讯会议；线下会议则看到「3 楼 小会议室」。

**③ 会中**
进入「会中记录」→ 随手记，遇到结论标「决议」，领了活标「待办」并写 `@我 周五前`，别人答应的写 `@李娜 周五前`。

**④ 会后**
点「结束会议」→ 自动生成纪要 → 核对待办 → 我负责的已出现在「今天 / 以后」，别人负责的进入「我跟进的」。

**⑤ 下次例会**
打开下周的产品周会 → 自动显示「上次留给我的待办：1 条未完成」。

## 6. 界面规划

| 页面 | 内容 |
| --- | --- |
| ① 会议日程（主界面） | 左侧 MyLog 边栏新增「会议」分组；中间是今天 / 本周会议列表；最近一场以大卡片显示倒计时和入会按钮；右侧显示待整理纪要和我的会议待办 |
| ② 新建会议 | 粘贴腾讯会议邀请自动识别；切换 腾讯会议 / 线下 / 混合；提醒与例会 |
| ③ 会议详情 · 会前 | 入会方式、上次留给我的待办、会前备注、参会人 |
| ④ 会中记录 | 按时间顺序的记录流 + 标记类型；旁边显示会前备注和上次待办 |
| ⑤ 会后纪要 | 自动整理的纪要、待办核对、导入腾讯会议智能纪要 |
| ⑥ 会议待办 | 我负责的 / 我跟进的 / 已完成，按会议分组 |

视觉风格沿用 MyLog：白底、浅灰边栏、一种主色（蓝），会议类型用三种浅色标签区分。

界面原型：见「会议管理原型」画布（6 屏），源文件在 [design/meeting-prototype](../design/meeting-prototype)。

## 7. 已确认的决策（10月22日）

1. **做成 MyLog 的模块**，会议待办直接进入「今天 / 以后」。
2. **腾讯会议个人版**：不对接开放平台，靠「粘贴邀请」录入会议、「粘贴智能纪要文字」补充记录。
3. **纪要自己记**：不做多人协同和分享链接；保留复制 / 导出，方便偶尔转给别人。
4. **不做录音转写**（暂不需要）。
5. **用户是参会者**：去掉议程、议程计时和签到；新增「会前备注」，用来记想问的问题和要带的资料。
